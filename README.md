# Audiobooks — APK

Android-плеер для аудиокниг: запоминает позицию, виджет на рабочий стол,
буст громкости до +25 дБ, 4-полосный эквалайзер, выбор глав.

## Установка
1. Скачайте `audiobooks.apk` на телефон (Android 64-bit, т. е. почти любой современный).
2. Откройте файл. Если телефон просит, разрешите установку из неизвестных источников.
3. Дайте приложению доступ к аудио/файлам, добавьте папку с книгой.

Виджет: долгое нажатие на главный экран, «Виджеты», «Аудиокниги».

> Сборка подписана отладочным ключом, предназначена для личного показа.
